# Project Summary
STAUBPFOTEN! ist ein deutschsprachiges Pixel-Art-Würfelabenteuer für einen Spieler und die ganze Familie. Als Halo oder Nand erkundet man einen zufällig zusammengestellten Weg durch den Brumsenbau, einen Wildbienenbau mit riesigen Bienen. Ziel ist die Hinogkammer.

Das Spiel besteht aus einzelnen Bildschirmen für Figurenauswahl, Karte, Räume und Spielende. Im Raum stehen Bild und Aufgabe im Mittelpunkt; eine kompakte Statusleiste zeigt Figur und Werte. Die Oberfläche ist für die Nutzung ohne Scrollen ausgelegt.

# Project Module Description
- **Figurenauswahl und Start:** Halo oder Nand auswählen und das Spiel starten.
- **Karte und Wegwahl:** Die Karte zeigt den Abenteuerweg. Nach Kammer 2 wird zwischen oberem und unterem Weg gewählt; die nicht gewählte Route wird ausgegraut. Nach einem Raum führt „Weiter zur Karte“ zurück zur Raumwahl.
- **Räume:** Bildschirm mit Raumbild, Name, Beschreibung und Aufgabe. Über „Karte“ kann die Karte jederzeit geöffnet werden.
- **Zufällige Räume:** Sieben Räume werden aus elf nummerierten Räumen ohne Königinnenkammer ausgewählt; ein Raum erscheint höchstens einmal.
- **Würfel und Regeln:** Eine W6-Probe gelingt, wenn der Wurf höchstens dem geprüften Wert entspricht. Fehlschläge kosten LP; bei 0 LP endet das Spiel. Eine gewürfelte 6 kostet 2 LP. Das letzte Würfelergebnis wird im Raum angezeigt.
- **Statusleiste:** Zeigt Figur, LP sowie GE, KK und KL. Der aktuell geprüfte Wert wird hervorgehoben. Eine Aktion ermöglicht den Neustart.
- **Königinnenkammer und Ziel:** In der Königinnenkammer müssen nacheinander KK- und GE-Probe gelingen. Danach folgt die Hinogkammer.
- **Gegenstand:** Die Laserwaffe im KI-Versteck erhöht KK und KL jeweils um 1. Sie ist verfügbar, wenn das Versteck ausgewählt wurde und auf dem gewählten Weg liegt.
- **Spielende:** Bei Erfolg zeigt der Sieg-Bildschirm ein großes, figurenspezifisches Hinog-Siegerbild und die verbleibenden LP, geschafften Kammern sowie den gewählten Weg. Bei 0 LP erscheint der Niederlagen-Bildschirm. Beide bieten einen Neustart.
- **Blog und Authentifizierung:** Blogseiten mit Prerendering sowie Authentifizierungs-Callback- und Fehlerseiten.

# File Description Inventory
- **`src/pages/Index.tsx`**: Steuert Spielstatus und Navigation zwischen Start, Karte, Raum und Spielende.
- **`src/components/game/MapScreen.tsx`**: Karten-Einstiegsbildschirm mit Abenteuerstart.
- **`src/components/game/ColonyMap.tsx`**: Raumkarte, Wegwahl und Auswahl des nächsten Raums.
- **`src/components/game/RoomScreen.tsx`**: Raumbild, Beschreibung, Aufgabe, Würfelaktion und letztes Wurfergebnis.
- **`src/components/game/StatusBar.tsx`**: Kompakte Anzeige von Figur, LP und Eigenschaften.
- **`src/components/game/Dice.tsx`**: Würfelanzeige.
- **`src/components/game/CharacterSelect.tsx`**: Figurenauswahl und Anzeige der Lebenspunkte (LP).
- **`src/components/game/EndScreen.tsx`**: Sieg- und Niederlagenansicht; zeigt beim Sieg das zur Spielfigur passende Hinog-Bild.
- **`src/game/data.ts`** und **`src/game/engine.ts`**: Figuren- und Raumdaten sowie Regeln, Proben, Wegwahl und Spielausgänge.
- **`src/game/assets.ts`** und **`image_manifest.json`**: Zuordnung und Manifest der Spielgrafiken.
- **`assets/images/win-halo-hinog.png`** und **`assets/images/win-nand-hinog.png`**: Figurenspezifische Hinog-Siegerbilder.
- **`src/components/blog/`**, **`src/pages/blog/`** und **`prerender/`**: Blog-Oberfläche, Beitragsseiten und Prerendering.
- **`src/components/ui/`**, **`src/hooks/`** und **`src/lib/`**: UI-Bausteine, Hooks und gemeinsame Hilfsfunktionen.
- **`src/App.tsx`**, **`src/main.tsx`**, **`src/App.css`** und **`src/index.css`**: App-Struktur, Einstieg und Styles.
- **`src/pages/AuthCallback.tsx`** und **`src/pages/AuthError.tsx`**: Authentifizierungsrouten.
- **`assets/images/`**: Pixel-Art für Spielfiguren, Spielwelt, Kammern und Gegenstände.
- **`attachments/`**: Raumdaten aus früheren Fassungen.

# Technology Stack
- React und TypeScript
- Vite
- Tailwind CSS und PostCSS
- Wiederverwendbare UI-Komponenten im Stil von shadcn/ui
- ESLint
- Playwright-Konfiguration
- Node.js und npm

# Usage
Im Frontend-Verzeichnis Abhängigkeiten installieren und die Entwicklungsfassung starten:

```bash
cd app/frontend
npm install
npm run dev
```

Produktionsbuild und Lint-Prüfung:

```bash
npm run build
npm run lint
```
